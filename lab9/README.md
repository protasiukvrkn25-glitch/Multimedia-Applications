# Лабораторна робота №9
## BC1 Encoder

**Мета роботи:** реалізувати алгоритм стиснення текстур BC1 та порівняти два методи вибору кінцевих кольорів: BBox і Pixel.

### Хід роботи

1. Реалізовано створення палітри кольорів BC1.
2. Реалізовано вибір кінцевих кольорів двома методами.
3. Реалізовано кодування зображень блоками 4×4.
4. Проведено тестування на фотографії, градієнті, normal map та різких кольорових переходах.
5. Обчислено RMSE та кутову похибку normal map.
6. Збережено результати кодування та карти різниці у папці `results`.

### Результати

Результати роботи програми збережені у папці `results` у форматі PNG.

### Висновок

Під час лабораторної роботи було реалізовано спрощений BC1 encoder. Проведено порівняння методів BBox і Pixel, досліджено похибки відновлення зображень та створено карти різниці.
