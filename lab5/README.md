\# Лабораторна робота №5



Тема: Субдискретизація кольору.



Мета: Навчитися виконувати перетворення RGB і YCbCr, реалізувати схеми субдискретизації 4:2:2 та 4:2:0 і дослідити похибки зображень.



\## Використані технології



\- Python

\- NumPy

\- Pillow

\- scikit-image

\- Matplotlib



\## Хід роботи



1\. Реалізовано перетворення RGB ↔ YCbCr.

2\. Реалізовано субдискретизацію 4:2:2 і 4:2:0.

3\. Створено тестові зображення тексту та кольорових ліній.

4\. Побудовано карти різниці для тексту й фотографії.

5\. Проведено вимірювання похибок для трьох схем.



\## Результати



Програма створює п'ять зображень для порівняння результатів субдискретизації та виводить таблицю вимірювань у термінал.



\## Висновок



Субдискретизація зменшує кількість даних про колір. На фотографіях похибки переважно малопомітні, але на дрібному кольоровому тексті та тонких лініях можуть бути помітні спотворення.і
